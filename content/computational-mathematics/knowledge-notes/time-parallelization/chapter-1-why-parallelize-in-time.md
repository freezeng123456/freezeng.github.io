## 1.1 论文关注的核心问题

时间并行（parallel-in-time，PinT）研究如何在大规模演化问题中继续增加并发度。传统做法主要沿空间方向分区。当空间子域已经很小，继续增加处理器会让通信、同步和负载不均衡占据更多时间。时间方向仍有大量未知量，因此自然成为新的并行维度。

困难来自演化问题的单向信息流：较晚时刻的状态由较早时刻决定。直接时间推进因此形成一条因果链。论文围绕这个矛盾展开：怎样在保持演化方程正确性的前提下，让多个时间区间同时产生有效计算？

作者先回顾按算法机制形成的四条研究谱系：

1. 多重打靶类方法；
2. 区域分解与波形松弛类方法；
3. 时空多重网格类方法；
4. 直接时间并行方法。

这套分类适合梳理算法来源，却难以直接判断方法在不同动力学上的表现。近年的计算经验表明，许多在抛物问题上表现良好的算法，进入双曲或输运占优区域后会明显退化。论文因此按适用问题重新组织材料：一组方法在双曲问题上仍然有效，另一组方法主要利用抛物动力学的耗散性质。

全文用四个偏微分方程贯穿讨论：热方程、对流扩散方程、Burgers 方程和二阶波动方程。它们从强耗散逐步过渡到持续传播，为比较时间并行算法提供了一条连续的物理主线。

## 1.2 硬件变化为何把时间方向推到前台

论文把过去二十余年的 PinT 发展放在硬件演进中理解。处理器主频逐渐接近物理和能耗约束，性能增长越来越依赖更多计算核心。摘要把 2004 年视为研究加速的转折点。多核结构已经出现在手机等小型设备中，高性能计算机则拥有数量巨大的核心。演化问题若只利用空间并行，能够有效使用的核心数会受到网格规模和空间通信的限制。

时间并行的设想远早于现代多核硬件。Nievergelt 在 1964 年提出用冗余计算换取并行性的原型方法。他当时更看重这条原则所展示的潜力：当计算机可以同时执行大量任务时，围绕同一思想发展出的算法将具有实际价值。

此后几十年间陆续出现了多种时间并行方法。Lions、Maday 和 Turinici 在 2001 年提出 Parareal 后，这一方向进入快速发展阶段。论文同时指向三类综述资料：Gander（2015）梳理历史，Ong 和 Schröder（2020）侧重应用，Gander 和 Lunet（2024）则给出系统性的专著说明。

## 1.3 因果性怎样形成串行计算链

考虑常微分方程及其前向 Euler 离散：

$$
\partial_t u=f(u),\qquad u(0)=u_0,\qquad
u_{n+1}=u_n+\Delta t\,f(u_n). \tag{1.1}
$$

递推式直接给出数据依赖。计算 $u_{n+1}$ 时，$u_n$ 必须已经可用。若 $u_9$ 还没有得到，处理器即使空闲，也无法按同一条前向 Euler 递推准确计算 $u_{10}$、$u_{11}$ 和 $u_{12}$。这正是论文 Figure 1.1 所强调的顺序性。

![原论文 Figure 1.1：前向 Euler 时间积分的串行依赖](assets/papers/time-parallelization/source-figures/figure-1-1.svg)

**Figure 1.1 逐图理解。** 横轴列出 $t_0$ 到 $t_{12}$，折线上的每个节点代表相应离散时刻的数值解。连接节点的线段把递推依赖画成一条连续路径：计算只能沿 $u_0,u_1,\ldots,u_{12}$ 的顺序前进。图中的曲线形状没有表达某个特定方程的精确解，它只用一条示意轨迹突出时间推进的先后关系。

PinT 算法保留原问题的因果约束，同时改变约束的计算方式。常见做法包括给时间界面提供暂定值并迭代校正、在完整时间窗上交换波形、建立粗时间层级，或把全时间耦合变换为一组可以并发求解的子问题。额外计算、迭代和通信由此产生，它们是换取时间并发度所付出的代价。

## 1.4 按算法机制形成的四条历史谱系

论文先沿用传统的四类划分。每一类都对应一种打破长时间递推链的思路。

| 谱系               | 历史起点与代表方法                                                                                                    | 如何组织跨时间耦合                                         |
| ------------------ | --------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 多重打靶           | Nievergelt（1964），Bellen-Zennaro（1989），Chartier-Philippe（1993），Saha-Stadel-Tremaine（1997），Parareal（2001） | 把长时间区间切成多个初值子问题，通过连续性条件校正各段初值 |
| 区域分解与波形松弛 | Schwarz 区域分解（1870），波形松弛（1982），Bjørhus（1995），SWR（1999）                                              | 在时空子域上求解，并在重叠区或界面交换整段时间波形         |
| 多重网格           | 抛物多重网格（Hackbusch，1984），STMG（Gander-Neumüller，2016）                                                       | 在时空网格层级之间平滑误差并进行粗网格校正                 |
| 直接时间并行       | 并行时间步进（Miranker-Liniger，1967），RIDC（2010），ParaExp（2013），时间对角化与 ParaDiag                          | 利用延迟校正、矩阵指数或时间矩阵的可对角化结构并发求解     |

多重打靶把一个长初值问题拆成多个短初值问题。各段可以同时计算，但段首状态需要通过全局连续性条件逐轮修正。Parareal 是这条路线中最有影响力的算法之一。

SWR 将空间区域分解与波形松弛结合起来。每个子域一次求解完整时间窗，迭代过程中交换的是界面上的时间函数。它和逐时间步通信相比具有不同的并行粒度，也便于利用双曲方程的有限传播速度。

时空多重网格把全部时间点与空间点放进统一层级。平滑器负责衰减局部误差，粗层负责传播长程信息。STMG 属于这条路线，第四章讨论的 MGRiT 也与多重网格思想密切相关。

直接时间并行方法利用离散系统的特殊代数结构。RIDC 通过延迟校正形成流水线，ParaExp 把非齐次响应与齐次传播分开，ParaDiag 则借助时间矩阵的对角化并行处理多个空间系统。

## 1.5 四类方法为何会相互交叉

传统分类的边界并不严格。论文列出多个关键联系：

- 前三类通常以迭代形式出现，第四类早期以直接方法为主；
- ParaDiag 最初通过时间步进矩阵的对角化构造直接求解器，随后出现了波形松弛形式和嵌入 Parareal 的迭代形式；
- 近似 ParaDiag 算子可以充当定常迭代，也可以预处理由时空离散得到的全时间系统，再交给 Krylov 方法求解；
- Parareal 可以解释为沿时间方向采用激进粗化的多重网格方法；
- MGRiT 也可以理解为带重叠结构的 Parareal 推广。

这些联系说明，同一个算法可以同时具有打靶、波形松弛、多重网格和全时间代数求解的特征。按技术来源分类有助于追溯思想，算法面对传播、耗散和非线性时的实际表现还需要单独分析。

## 1.6 论文采用的双重分类

论文最终按照“能够有效处理哪类问题”组织第三、第四节。

### 对双曲问题仍然有效的方法

这一组包含 Schwarz 波形松弛及其与 tent pitching 的联系、并行积分延迟校正、ParaExp 和 ParaDiag。它们通常也适用于抛物问题。共同点在于算法能够处理传播信息，或通过全局代数结构减少对耗散型粗传播子的依赖。

### 主要为抛物问题设计的方法

这一组包含 Parareal、PFASST、MGRiT 和 STMG。它们充分利用耗散带来的误差衰减与尺度分离，在热方程等问题上往往很有效。进入双曲极限后，粗传播和粗层校正较难保留相位与传播路径，收敛可能随之变慢。

第二节先用四个模型问题解释抛物与双曲动力学的差异；第三节介绍前一组方法；第四节讨论后一组方法；第五节总结。论文第 2-4 节的 MATLAB 代码公开在 [wushulin/ActaPinT](https://github.com/wushulin/ActaPinT)。本站的 Python 转换与扩充版本位于 [freezeng123456/ActaPinT-Python](https://github.com/freezeng123456/ActaPinT-Python)。

## 1.7 从递推关系到全时间系统

下面给出一层代数补充。它没有改变公式 (1.1) 的因果关系，只把所有时间点的未知量同时写入一个线性系统。

对线性单步离散，设

$$
u_{n+1}-\Phi u_n=g_{n+1}.
$$

令 $g_0:=u_{\mathrm{init}}$ 表示给定初值。于是把 $u_0$ 也纳入未知向量后，

堆叠全部时间未知量可得

$$
\begin{bmatrix}
I \\
-\Phi&I\\
&-\Phi&I\\
&&\ddots&\ddots
\end{bmatrix}
\begin{bmatrix}u_0\\u_1\\u_2\\\vdots\end{bmatrix}
=
\begin{bmatrix}g_0\\g_1\\g_2\\\vdots\end{bmatrix}.
$$

串行时间推进等价于对这个块下三角系统做精确前代。主要 PinT 方法族为它构造不同的并行近似：

- Parareal 和 MGRiT 使用低成本粗传播与粗时间层级；
- STMG 在完整时空网格上构造多层校正；
- ParaDiag 用可经 FFT 对角化的循环或近循环时间矩阵近似原系统；
- SWR 在时空子域上求解并交换界面波形；
- 延迟校正方法把校正过程排成可以重叠执行的流水线。

这个视角解释了一个容易混淆的事实：时间并行的并发工作发生在迭代、分解、变换或校正流水线内部。最终解仍然满足离散演化方程规定的时间关系。

## 1.8 双曲问题为何更难：一个先导判断

对耗散传播子，许多误差模态满足 $|\lambda(\Phi)|<1$。快速衰减的分量在长时间尺度上影响较小，粗时间模型即使无法精确表示这些分量，也可能提供有效校正。

波动和输运问题中的重要模态更接近单位圆。误差常表现为相位偏移或传播位置偏差。细、粗传播之间很小的相位失配会跨越多个时间区间累积。由此可以预期：

1. 对流扩散方程的黏性 $\nu$ 下降时，标准时间粗化会越来越困难；
2. 输运占优区域中的 Parareal 可能经历暂态误差增长；
3. 特征线传输、相位校正、波形松弛和全局对角化值得优先考虑。

第二章会通过热方程、对流扩散方程、Burgers 方程和波动方程逐步建立这一判断。

## 1.9 如何判断实际并行收益

收敛曲线只能回答算法误差如何下降。并行效率还受到粗细求解成本、通信、内存与可扩展性的共同影响。

| 指标       | 要回答的问题                               |
| ---------- | ------------------------------------------ |
| 收敛性     | 需要多少次全局迭代才能达到离散误差量级？   |
| 粗细成本比 | 粗传播子是否显著低于细传播子成本？         |
| 时间并发度 | 可以同时执行多少个细求解或局部求解？       |
| 通信       | 每轮迭代使用邻居交换还是全局集合通信？     |
| 内存       | 是否需要保存全部时间状态？                 |
| 参数鲁棒性 | 动力学接近双曲极限时收敛如何变化？         |
| 可扩展性   | 时间区间增加后，迭代次数与通信量是否受控？ |

对含 $N$ 个时间区间的 Parareal，忽略通信时，一个理想化加速上界为

$$
S\lesssim \frac{NC_F}{K(C_F+NC_G)}.
$$

这里 $C_F$ 和 $C_G$ 分别表示细、粗传播成本，$K$ 是全局迭代数。取得有效加速需要 $K\ll N$ 且 $C_G\ll C_F$。收敛本身无法保证这两个条件成立。

## 小结

论文第一节完成了三件事：从硬件并行度解释研究动机，用前向 Euler 说明时间因果链，再从传统四类方法转向按问题性质组织的双重分类。后续各章都围绕一个判断展开：算法怎样传递跨时间信息，以及这种机制能否保留耗散、相位和有限传播速度等关键动力学特征。
