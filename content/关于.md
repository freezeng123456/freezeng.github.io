这个知识库服务于三个目的：

1. 把科研项目压缩成可复用的“问题—洞见—算法—结果—边界”结构；
2. 把长论文拆成可以逐章学习、逐个算例验证的知识网络；
3. 把大型工程从代码目录还原成数据流、控制流、参数流和稳定性闭环。

## 证据等级

| 标记     | 含义                                   |
| -------- | -------------------------------------- |
| 已证明   | 有定理、推导或严格等价关系支撑         |
| 已验证   | 有代码、固定协议和可检查数值结果       |
| 工程约束 | 来自当前实现、配置或部署边界           |
| 待确认   | 仍需多种子、消融、线上灰度或负责人确认 |

内容会主动区分数学保证、实验观察和工程经验，避免把三者混写成同一种结论。

## 信息安全

站点源文件不得出现密码、密钥、Cookie、内网地址、人员身份信息或真实业务样本。OneRec 专题在内部评审结束后应迁移到私有知识库或从公开站点删除；Git 历史仍可能保留旧内容，因此“删除页面”不等于“撤销泄露”，公开前需要再次审计完整提交历史。
