本页记录与论文配套的 Python/SciPy 复现。项目从原 MATLAB 算例出发，实现了解模型、Parareal、MGRiT、ParaDiag-II 与 STMG，并保留 JSON 结果以便自动核验。

## 项目结构

```text
actapint/
  integrators.py       # 时间积分
  operators.py         # PDE 空间离散与线性算子
  experiments.py       # 基础方法实验
  paper_validation.py  # 论文图对应验证
run_experiments.py     # 统一入口
results/
  paper/               # 正式验证图与 JSON
```

当前实现以 NumPy/SciPy 稀疏算子和 FFT 为主，运行环境虽然有 T4 GPU，但这些实验没有宣称 GPU 加速。

## ParaDiag-II：预条件与黏性

![[assets/pint/paradiag-ii-validation.png]]

验证参数选择两个黏性尺度。结果：

| 黏性 $\nu$ | 达到机器精度附近的 GMRES 步数 | 解释                               |
| ---------: | ----------------------------: | ---------------------------------- |
|  $10^{-3}$ |                             3 | 耗散足够强，循环预条件与原系统接近 |
|  $10^{-6}$ |                            13 | 接近输运极限，相位模更难预处理     |

`GMRES tolerance` 决定终止残差；它不应远小于空间/时间离散误差，除非目标是验证线性代数实现。

## Parareal：非线性与耗散

![[assets/pint/parareal-validation.png]]

达到 $10^{-10}$ 最大误差所需迭代：

| 模型      | $\nu=1$ | $\nu=0.1$ | $\nu=0.02$ |
| --------- | ------: | --------: | ---------: |
| 对流–扩散 |      14 |        24 |         35 |
| Burgers   |      14 |        21 |         25 |

这里的迭代数用于复现收敛趋势，不直接等价于并行加速。真实加速还需要粗/细传播时间与进程通信。

## Parareal 与 MGRiT 的耗散依赖

![[assets/pint/parareal-mgrit-validation.png]]

| 问题            | Parareal 因子 | FCF-MGRiT 因子 | 判断                   |
| --------------- | ------------: | -------------: | ---------------------- |
| Heat            |         0.282 |          0.084 | 两者稳定，MGRiT 更快   |
| ADE $\nu=0.1$   |         0.445 |          0.272 | 稳定                   |
| ADE $\nu=0.01$  |         1.050 |          0.902 | 临界，MGRiT 勉强收敛   |
| ADE $\nu=0.002$ |         1.421 |          1.281 | 早期增长，标准粗化失效 |

图中使用“等成本迭代”比较：一次 FCF-MGRiT 与两次 Parareal 的细传播工作量近似对齐。该横轴比单纯 iteration 更接近算法成本，但仍未包含通信。

## STMG：阻尼与平滑步数

![[assets/pint/stmg-damping.png]]

- 热方程最优阻尼约 $\eta=0.5$；
- ADE $\nu=0.01$ 的最优值约 $\eta=0.37$；
- $\eta=0.5$ 是跨这组问题的稳健默认值，不是所有参数下的严格最优。

![[assets/pint/stmg-smoothing.png]]

三次前/后平滑相较一次显著减少 V-cycle 数。实际选择应最小化

$$
\text{work-to-tolerance}
= (\text{每 cycle 工作量})\times(\text{cycle 数}),
$$

而不是盲目增加平滑次数。

## 如何复现

```bash
python -m pip install -r requirements.txt
python run_experiments.py paper_validation
```

正式结果应满足：

1. 每个图同时生成 JSON；
2. JSON 记录网格、黏性、迭代容差和误差；
3. 图中曲线与 JSON 数值可互相核对；
4. quick 配置只用于冒烟测试，不与正式网格结果混报。
