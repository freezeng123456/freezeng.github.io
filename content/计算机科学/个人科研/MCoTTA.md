## 研究问题

LCoTTA 在 continual test-time adaptation 中收集熵梯度快照，使用滑动窗口 PCA 得到低秩子空间，再把当前梯度投影到这个子空间中更新模型。问题在于：单批次原始梯度含有较强瞬时噪声，PCA 队列可能持续追逐短期方向，而不是追踪污染流中的慢变化结构。

核心观察是，PCA 按历史方差选择方向，但 continual adaptation 真正需要的是对后续 batch 仍然有解释力的方向。高方差不等于时间上可持续。短暂但幅值较大的梯度变化可能占据有限的子空间容量，而较平稳的方向反而被排除。

## 算法

原方法把当前过滤梯度 $g_t$ 直接写入 PCA 队列：

$$
\mathcal Q_t\leftarrow g_t.
$$

MCoTTA 维护指数动量：

$$
m_t=\beta m_{t-1}+(1-\beta)g_t,
\qquad
\mathcal Q_t\leftarrow m_t.
$$

对动量历史做中心化 rank-$r$ PCA，得到投影矩阵 $P_t^M$。真正用于更新的仍是当前梯度：

$$
\tilde g_t=P_t^M g_t,
\qquad
\theta_{t+1}=\theta_t-\eta\tilde g_t.
$$

算法刻意分开两条路径：

- **估计路径**：$g_t\rightarrow m_t\rightarrow\mathcal Q_t\rightarrow P_t^M$；
- **更新路径**：$g_t\rightarrow P_t^M g_t\rightarrow\theta_{t+1}$。

动量状态只决定允许在哪些方向上适应，当前 batch 仍决定沿这些方向更新多少。方法没有增加 teacher–student 网络、memory bank、额外损失或新的可训练参数。

## 理论洞见

把梯度写成时间上持续的低秩分量与较快变化的残差：

$$
g_t=s_t+\epsilon_t.
$$

指数平均会降低不相关残差的相对协方差权重，同时保留跨 batch 相关的分量。由此得到的核心判断不是“动量梯度更准确”，而是：

> 动量历史更适合估计未来仍会出现的更新子空间，当前梯度仍应负责实际参数更新。

理论给出 population covariance 层面的 persistent-energy ordering。它解释了为何平滑历史可能比原始梯度历史更适合做子空间估计，但不把“保留更多未来能量”等同于“每个方向都能提高分类准确率”。

## 主实验协议

三项任务均采用 corruption severity 5、全部 15 种 corruption、连续单次遍历、边界处不 reset、batch size 64，并对每个 seed 使用相同的随机流进行 LCoTTA/MCoTTA 配对。

| 任务                     | 每个 corruption 样本数 | $W$ | $r$ | $K$ | 主设置 $\beta$ |
| ------------------------ | ---------------------: | --: | --: | --: | -------------: |
| CIFAR-100-C / ResNeXt-29 |                 10,000 | 100 |  25 |  50 |           0.99 |
| ImageNet-C / ResNet-50   |                 50,000 | 100 |  25 |  50 |           0.99 |
| ImageNet-C / ViT-B/16    |                 50,000 | 100 |  50 | 100 |           0.99 |

这里 $W$ 是 PCA 队列长度，$r$ 是子空间秩，$K$ 是梯度快照间隔。

## 三种子配对结果

遗漏分支合入后，三个任务都具有完整的三种子配对结果。下表为 accuracy 的 mean ± sample standard deviation：

| 任务                     |        LCoTTA |            MCoTTA | 配对平均提升 |
| ------------------------ | ------------: | ----------------: | -----------: |
| CIFAR-100-C / ResNeXt-29 | 65.37 ± 0.21% | **66.00 ± 0.09%** |    **+0.63** |
| ImageNet-C / ResNet-50   | 36.79 ± 0.17% | **43.97 ± 0.38%** |    **+7.18** |
| ImageNet-C / ViT-B/16    | 60.18 ± 0.40% | **62.98 ± 0.54%** |    **+2.80** |

三个 seed 的逐项配对提升分别为：

| 任务                     | seed 1 | seed 2 | seed 3 |
| ------------------------ | -----: | -----: | -----: |
| CIFAR-100-C / ResNeXt-29 |  +0.54 |  +0.94 |  +0.42 |
| ImageNet-C / ResNet-50   |  +7.75 |  +6.90 |  +6.89 |
| ImageNet-C / ViT-B/16    |  +2.94 |  +2.80 |  +2.66 |

结果的主证据集中在两个 ImageNet-C 设置。CIFAR-100-C 的提升在三个 seed 上方向一致，但幅度明显更小，因此不将其描述为跨任务的同量级收益。

## 因果机制诊断

分类结果会同时受到“子空间质量”和“不同更新轨迹”的影响。为隔离前者，shared-gradient replay 固定 ImageNet-C / ResNet-50 的梯度轨迹、冻结模型，并让不同 tracker 接收完全相同的梯度序列。评估只使用随后到达的 1–49 个 batch，排除当前快照 $k=0$。

在 $W=100$、$r=25$、$K=50$ 和 6,595 条评分记录下：

| 子空间历史          | 未来梯度平均能量保留 |
| ------------------- | -------------------: |
| 原始梯度            |              1.3275% |
| 动量，$\beta=0.5$   |              1.7891% |
| 动量，$\beta=0.7$   |              2.5831% |
| 动量，$\beta=0.9$   |              3.3133% |
| 动量，$\beta=0.99$  |          **3.6882%** |
| 动量，$\beta=0.999$ |              3.6491% |

$\beta=0.99$ 的保留率约为原始梯度历史的 2.78 倍；到 $\beta=0.999$ 后没有继续上升，说明过强平滑开始出现收益饱和。

## 参数与消融

### 动量系数

单 seed 的完整 $\beta$ sweep 显示，较大的动量在两个 ImageNet-C 设置上更重要：

| $\beta$ | CIFAR-100-C / ResNeXt-29 | ImageNet-C / ResNet-50 | ImageNet-C / ViT-B/16 |
| ------: | -----------------------: | ---------------------: | --------------------: |
|    0.10 |                   65.69% |                 36.94% |                44.18% |
|    0.30 |                   64.95% |                 38.02% |                60.40% |
|    0.50 |                   65.00% |                 38.52% |                60.80% |
|    0.70 |                   65.66% |                 40.33% |                60.31% |
|    0.90 |                   66.06% |                 43.03% |                62.63% |
|    0.99 |                   66.04% |             **44.39%** |                63.56% |
|   0.999 |               **66.16%** |                 43.77% |            **64.07%** |

$\beta=0.99$ 不是每个单任务上的孤立最优点，但在三项任务上表现稳定，因此用作三种子主实验设置。

### 子空间秩

rank 消融说明更大的子空间并不自动更好：

| 任务                     |     $r=10$ | $r=50$ |     $r=75$ |
| ------------------------ | ---------: | -----: | ---------: |
| CIFAR-100-C / ResNeXt-29 | **66.52%** | 65.99% |     66.17% |
| ImageNet-C / ResNet-50   | **43.01%** | 42.26% |     40.31% |
| ImageNet-C / ViT-B/16    |     62.92% | 63.46% | **63.51%** |

ResNet-50 随 rank 增大而明显下降，说明额外方向可能重新引入瞬时变化。ViT 对较高 rank 更宽容，因此主配置采用 $r=50$。

### 队列长度

在 $r=25$、$K=50$ 的统一消融设置下：

| 任务                     |     $W=35$ |     $W=50$ |     $W=75$ |
| ------------------------ | ---------: | ---------: | ---------: |
| CIFAR-100-C / ResNeXt-29 |     66.04% | **66.21%** |     65.73% |
| ImageNet-C / ResNet-50   |     42.26% |     43.07% | **43.50%** |
| ImageNet-C / ViT-B/16    | **64.12%** |     64.09% |     63.39% |

ViT 的窗口消融使用 $r=25,K=50$，与其主实验的 $r=50,K=100$ 不同，因此不能把表中结果与主实验 $W=100$ 做单变量比较。

## 长时程行为

ImageNet-C / ResNet-50 的 $\beta=0.9$ 实验完成了 10 个 cycle。LCoTTA 从 36.83% 降至 35.79%，MCoTTA 从 42.43% 降至 39.76%。MCoTTA 在每个 cycle 都更高，但优势随时间缩小，两者都没有避免长期漂移。

CIFAR-100-C / ResNeXt-29 的 seed 2、$\beta=0.9$ 配对实验同样完成 10 个 cycle：

| 方法   |    cycle 1 |       峰值 |   cycle 10 |
| ------ | ---------: | ---------: | ---------: |
| LCoTTA |     65.47% |     65.78% |     65.68% |
| MCoTTA | **66.16%** | **66.83%** | **66.10%** |

该任务上分类收益较小，但 10-cycle 结果没有出现 ImageNet-C / ResNet-50 那样明显的持续退化。

## 科学边界

- 三种子结果已经完整，但样本量仍不足以替代更大规模统计检验。
- 机制结论是“动量子空间保留更多未来梯度能量”，不是证明每个被保留的方向都对分类有益。
- 两个 ImageNet-C 设置的提升明显，CIFAR-100-C 的效果较小，不能声称所有数据集获得同量级收益。
- 长时程实验说明 MCoTTA 改善了更新方向，但没有解决无限期持续适应的漂移。
- 原始 Raw-PCA 在“先写入当前梯度，再投影当前梯度”时具有 in-sample 自包含效应。严格因果对照应先投影、后写入快照；相关结论必须与现有实验分开陈述。
