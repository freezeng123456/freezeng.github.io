## 在线路径

在线日志经过预过滤和特征解码，延迟一段归因窗口后进入 OneRec 样本生成：

```text
DatahubLog
  → PreFilter
  → LogToFeature
  → attribution delay
  → OneRecGenerateSequence
  → USD enrichment
  → SequenceExample / training data
```

输入不是一个扁平 feature map，而是多种语义来源：

- 压缩的用户特征数据；
- feature list；
- PageView/position；
- BizTimeline 上下文；
- WUID 长序列与会话补全；
- 内容/广告 ID embedding。

## USER 与 CONTEXT 路由

特征先按来源和白名单进入两个基础 entry：

### USER

来自稳定用户画像与直接 user stream。只有 `userIntFeatureIdSet` 中允许的特征进入 USER；少量特殊特征会显式改路到 CONTEXT。

### CONTEXT

聚合 request、page、position、label、mix 与 list 类特征，并用 `contextFeature` 集合做过滤。它描述的是“这一次决策处境”，而不是长期用户属性。

一个硬门槛是：初始训练数据的第一个 USER entry 不能为空。若 USER 被白名单或解码错误清空，后续即使 CONTEXT 完整，样本也会被拒绝。

## USD 序列补全

基础 USER/CONTEXT 之后，USD 负责加入：

- 主行为序列；
- 辅助 item/content 序列；
- 会话内内容序列；
- 特定业务形态的 session completion；
- ID embedding 补全；
- 时间截断与最大长度限制。

重要实现事实：最终 entry **不是全局按事件时间排序**，而是按固定 slot 顺序拼接，例如：

```text
USER
CONTEXT
[optional] CONTENT_INTRA_SESSION
ITEM_AUX
CONTENT_AUX_*
CONTENT_AUX
ITEM / CONTENT main sequence
```

slot 内部可以保留时间顺序，但 slot 间的数组位置承载语义。训练模型的 feature reader 若把它当成单一时间序列重新排序，会破坏 schema。

## 离线路径

离线 Burn 从持久化 WUID 与用户列读取基础特征，再复用 USD 序列构造逻辑。目标不是代码完全相同，而是输出语义一致：

| 维度         | 在线            | 离线需对齐           |
| ------------ | --------------- | -------------------- |
| USER 白名单  | 实时流过滤      | 同版本集合           |
| CONTEXT 来源 | 请求现场        | 日志重建同字段       |
| 延迟归因     | 固定窗口        | 相同 cutoff          |
| 序列截断     | 在线 USD        | 同长度/时间规则      |
| slot 顺序    | 固定 entry 布局 | 完全一致             |
| ID embedding | 在线补全        | 同版本或明确缺失策略 |

批量离线路径中部分外部 embedding 补全可能关闭，因此必须用缺失标记或版本字段让模型区分，不能静默填零后假装与在线等价。

## 双实现迁移风险

当前还存在另一套并行样本生成实现，逻辑目标相同但配置和过滤入口不同。迁移时最危险的不是编译问题，而是**两套白名单和 slot 定义缓慢漂移**。

建议建立 golden sample：

1. 固定脱敏原始输入；
2. 两条实现分别输出 SequenceExample；
3. 对 entry 类型、数量、顺序、feature id、序列长度和 cutoff 逐字段 diff；
4. 对允许差异建立显式 allowlist；
5. 任何 schema 变化必须同时更新 reader 和 golden sample。

## 常见故障定位

| 症状                          | 首查                                    |
| ----------------------------- | --------------------------------------- |
| 样本量突然下降                | USER 空门槛、预过滤、归因延迟           |
| 在线好、离线差                | 白名单版本、序列 cutoff、embedding 补全 |
| 某类上下文特征为零            | USER/CONTEXT 路由集合                   |
| 序列长度正常但效果差          | slot 顺序、时间单位、跨会话拼接         |
| 训练可跑、线上 Decoder 空结果 | schema/model version 不一致             |
