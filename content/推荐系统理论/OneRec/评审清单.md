## 高层结论

OneRec 已形成“语义 ID—训练样本—序列模型—在线生成式召回—现有广告链路—反馈”的闭环。新路径与主路径隔离召回和精排资源，在合并前保持侧路可失败，并通过公共下游实现统一约束。

当前评审重点不是算法是否能生成 SID，而是以下工程闭环是否可靠：

- 训练/在线 schema 与模型/KV 版本；
- beam 与候选预算的层级关系；
- 多广告位参数隔离；
- async cache 与 Ranking 超时预算；
- 新旧路径的同口径监控和瞬时回滚。

## 逐项确认

### 数据

- [ ] USER/CONTEXT 白名单有单一版本源；
- [ ] 在线/离线 slot 顺序和 cutoff 有 golden diff；
- [ ] USER 空门槛、延迟归因与序列补全有量级监控；
- [ ] 并行样本生成实现的允许差异有文档；
- [ ] schema 版本进入样本与模型元数据。

### 语义 ID

- [ ] codebook hash、层数、位宽、pack version 绑定发布；
- [ ] collision、code usage、死码和 KV coverage 达标；
- [ ] RQ-VAE checkpoint 选择不只看 reconstruction；
- [ ] SID→TID 版本错配可在看板上直接识别。

### 训练

- [ ] 候选池、采样数、返回数和 $M$ 的大小关系合法；
- [ ] reward 单位、归一化、缺失值和版本明确；
- [ ] 并发 reward RPC 不并发写共享 protobuf map；
- [ ] 模型 reader 与线上 Encoder schema checksum 一致；
- [ ] frozen replay / causal control 与主实验分开报告。

### 在线召回

- [ ] 同 position 新旧路径互斥；
- [ ] 多 position 参数、cache node、tag 独立；
- [ ] 六个 Op 的 input/output/latency/fail 可观测；
- [ ] SID/TID/AID/广告漏斗完整；
- [ ] 公共下游按 `recall_path` 对比；
- [ ] OneRec 部分失败不扩大为主链路失败。

### Beam

- [ ] 新路径 `beam_width ≤ 180`；
- [ ] 旧路径默认 200 没有误入新路径；
- [ ] 每层 beam、最终 top-k、graph bucket 被分别记录；
- [ ] 调优同时看有效广告增益、P99 与显存；
- [ ] KV quota/Z-order 不被 beam 扩大压垮。

### 稳定性

- [ ] 请求级与 set 级两层回滚均演练；
- [ ] Fetch timeout 大于可接受的 pipeline P99 且不突破主链路预算；
- [ ] 灰度护栏按 position/机型分桶；
- [ ] cache 写入量与 Fetch 返回量可交叉验证；
- [ ] legacy 下线前完成反向切流演练。
