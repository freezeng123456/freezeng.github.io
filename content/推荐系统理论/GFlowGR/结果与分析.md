## 1. 主结果怎么读

论文在 Beauty、Instruments、Yelp 上，把 GFlowGR-DB / TB 接到 TIGER 与 LETTER，并和 SFT、GRPO、DPO、S-DPO、SPRec、IPA 对比。公开表中的稳定结论是：

1. **GFlowGR 全面强于 SFT**：增强轨迹、流匹配和价值对齐共同起作用；
2. **TB 通常优于 DB**：标识中间状态不唯一对应商品，整条轨迹优化更合适；
3. **On-policy GRPO 不稳**：它更像在集合内抬高正样本，难以覆盖集合外高价值区域；
4. **Off-policy 里 S-DPO 最接近**：多负样本很重要，但仍然缺少 token 级流监督。

以 LETTER + Beauty 为例，论文报告：

| 方法 | R@5 | R@10 | N@5 | N@10 |
| ---- | --: | ---: | --: | ---: |
| SFT | 0.0344 | 0.0540 | 0.0227 | 0.0290 |
| S-DPO | 0.0390 | 0.0607 | 0.0259 | 0.0336 |
| GFlowGR-DB | 0.0407 | 0.0630 | 0.0266 | 0.0337 |
| GFlowGR-TB | 0.0433 | 0.0672 | 0.0286 | 0.0363 |

复现时优先核对 **相对排序** 和 **相对升幅方向**，不要死盯绝对小数；不同框架实现、beam 配置和早停策略都会平移基线。

## 2. 超参：为什么是反向 V

$N$ 与 $\lambda$ 都呈反向 V：

- $N$ 太小：稀疏数据缺少多样性，set-wise 目标建立不起来；
- $N$ 太大：增强样本噪声上升，开始误导训练；
- $\lambda$ 太小：GFN 几乎不起作用；
- $\lambda$ 太大：冲掉 $\mathcal{L}_{\mathrm{GR}}$，基础 next-item 能力受损。

实践上先锁 $N=3$、$\lambda=1$，再在邻域细调。这比一上来网格搜索更稳。

## 3. 消融说明组件是否必要

论文在 LETTER + Beauty 上的消融给出四个关键信号：

1. **任一奖励信号缺失都掉点**，交互信号 $r_a$ 影响最大；
2. **随机采样弱于 CM 课程采样**，说明增强样本质量决定稳定性；
3. **$N=1$（无增强轨迹）泛化更差**，证明只靠单正样本不够；
4. **完全去掉 CM 仍可保持较强结果**，说明方法不只是“把协同分塞进 LLM”。

奖励融合对比：

| 策略 | 结论 |
| ---- | ---- |
| Sum | 默认强基线，实现最简单 |
| Weighted Sum | top-5 进一步提升，推荐作为第二默认 |
| Deep Integration | 过度参数化，无明显收益 |

## 4. LLM 增强与多样性

两类轻量增强都有效：

- **LLM sampling**：从 CM 过滤池里按生成置信度取样本；低置信样本更利于探索，R@5 / N@5 提升更明显；
- **LLM reward**：把归一化生成概率当作附加奖励，无需额外推理。

多样性分析（TIGER + Beauty）显示：相对 SFT，GFlowGR 的生成分布更接近正态、标准差更小，同时协同分范围更宽。案例上，SFT 更容易重复用户近期同款香型；GFlowGR 能扩到同品牌但不同功效/香型的高价值组合。

## 5. 工业部署结论

论文报告自 2025 年 5 月起，GFlowGR 用于淘宝搜索广告相关 GR 训练。公开可引用的结论包括：

- 离线生产数据上，相对 SFT / GRPO，H@20 与 N@20 提升；
- 同等 80× 样本量下，GFlowGR 训练成本约为 SFT 的 2.1×；
- 15 天、10% 流量 A/B 观察到总收入约 +0.43%；
- 新品与长尾查询收益更高，item coverage 也有小幅上升。

这些数字用于理解 **方法已被大规模验证**，不是公开复现的验收指标。公开复现仍以三个学术数据集为准。

## 6. 对工程落地的启示

若要把 GFlowGR 接到现有生成式召回：

1. **先保证 SFT 与 tokenizer 版本稳定**，再叠加 GFN；
2. **奖励尺度必须可解释**：交互层级、协同分、token 相似要分开日志；
3. **采样课程要可回放**：记录每个 step 的难度分位，避免线上数据漂移后课程失效；
4. **推理零侵入**：用同一套 beam / 约束解码对比 SFT 与 GFlowGR checkpoint；
5. **和 OneRec 类 GRPO 路径对比时**，关注“概率是否被强制在集合内归一”：GFlowGR 强调 $P(\tau)\propto R$，不要求候选集合概率和为 1。
