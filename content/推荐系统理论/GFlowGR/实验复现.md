## 复现目标

在公开数据上验证两件事：

1. 把 GFlowGR 接到 TIGER / LETTER 后，相对 SFT 与常见 RLFT 基线稳定提升；
2. 关键消融成立：CM 课程采样、多信号奖励、以及 $N$ / $\lambda$ 的反向 V 曲线。

官方仓库目前仅有 README，代码仍在准备发布。因此复现应以论文设定为准，在已有 GR 开源骨架上实现三组件，而不是等待私有脚本。

## 1. 数据与切分

| 数据集      |  Users |  Items | Sparsity | Avg.length |
| ----------- | -----: | -----: | -------: | ---------: |
| Yelp        | 30,431 | 20,032 |   99.85% |       9.39 |
| Beauty      | 22,362 | 12,101 |   99.92% |       7.87 |
| Instruments | 24,772 |  9,922 |   99.99% |       7.32 |

预处理遵循 LETTER：

- Beauty / Instruments：用 title + description 做 tokenization 输入；
- Yelp：用 title + description + brand + category；
- 切分：每个用户最后一次交互做测试，倒数第二次做验证，其余做训练。

实现检查：

- 用户序列严格按时间排序，禁止把测试 item 泄漏进 prompt；
- tokenizer 训练只能看训练期 item 文本特征；
- 同一用户的 train / val / test 目标互不重叠。

## 2. Backbone 与基线

安装 GFlowGR 到两个 GR backbone：

- **TIGER**：经典 RQ-VAE 标识 + 生成式检索骨架；
- **LETTER**：在 tokenization 中加入协同嵌入与多样性约束。

对比三类微调：

| 类别            | 方法                      | 复现时注意                                            |
| --------------- | ------------------------- | ----------------------------------------------------- |
| SFT             | next-token prediction     | 必须先跑通，作为所有增益的参照                        |
| On-policy RLFT  | GRPO                      | 组内相对优势，不强制覆盖集合外 item                   |
| Off-policy RLFT | DPO / S-DPO / SPRec / IPA | S-DPO 可吃多负样本；IPA 使用与 GFlowGR 相同的协同奖励 |

指标：R@5、R@10、N@5、N@10。每个实验用 seed `{42,43,44}` 重复三次，报告均值。

## 3. 默认超参

论文默认 ensemble：

- 轨迹采样：CM-based curriculum；
- 奖励：$R=r_a+r_{\hat{y}}+r_{\mathrm{sim}}$；
- 损失：$\mathcal{L}_{\mathrm{GR}}+\lambda\sum\mathcal{L}_{\mathrm{GFN}}$；
- 早停：Transformer Trainer early stopping。

敏感性搜索范围：

| 超参               | 搜索网格                | 经验最优点 |
| ------------------ | ----------------------- | ---------- |
| 增强轨迹数 $N$     | $\{0,1,3,5\}$           | 约 $3$     |
| 损失权重 $\lambda$ | $\{0.01,0.1,1,10,100\}$ | 约 $1$     |

$N=0$ 等于几乎退回单正样本；$N=5$ 易引入噪声；$\lambda\ge 10$ 会压过 SFT，损害基础推荐能力。

## 4. 最小可运行实现清单

按模块落地，而不是一次性重写整个 GR 系统：

1. **Tokenizer / Backbone**
   - 复用 TIGER 或 LETTER 的已有训练脚本；
   - 固定标识长度 $L=3$，并导出 item → token 映射。
2. **Collaborative Model**
   - 训练一个可打分的序列推荐或双塔模型，作为 $\mathrm{CM}(U,v)$；
   - 缓存 user-item 分数，供采样和奖励复用。
3. **Trajectory Sampler**
   - 输入正样本，输出 $N$ 条 token 轨迹；
   - 至少实现 random 与 CM curriculum 两档，便于消融。
4. **Reward Model**
   - 输出 $r_a$、$r_{\hat{y}}$、$r_{\mathrm{sim}}$；
   - 先做 Sum，再可选 Weighted Sum。
5. **GFN Loss**
   - 从 LLM logits 取轨迹上的 $P_{\mathrm{GR}}$；
   - 实现 DB 与 TB；TB 作为主结果，DB 作为对照。
6. **Trainer**
   - 每个 batch：正样本 SFT + 全集合 GFN；
   - 日志记录 $\mathcal{L}_{\mathrm{GR}}$、$\mathcal{L}_{\mathrm{GFN}}$、平均奖励、采样难度。

伪代码：

```python
for batch in loader:
    prompt, positive, aug_items = sample_trajectories(batch, N, strategy="cm_curriculum")
    trajectories = [positive, *aug_items]
    sft_loss = next_token_loss(model, prompt, positive)
    gfn_loss = 0.0
    for traj in trajectories:
        logp = token_logprobs(model, prompt, traj)
        reward = r_a(traj) + r_cm(traj) + r_sim(traj, positive)
        gfn_loss += trajectory_balance(logp, reward, Z)  # or detailed_balance(...)
    loss = sft_loss + lambda_gfn * gfn_loss
    loss.backward(); optimizer.step()
```

## 5. 建议实验顺序

1. **SFT baseline**：在 Beauty + TIGER 上先对齐公开量级；
2. **GFlowGR-TB default**：CM 采样 + Sum 奖励 + $\lambda=1$ + $N=3$；
3. **GFlowGR-DB**：同设定对照；
4. **超参曲线**：扫 $N$ 与 $\lambda$，确认反向 V；
5. **消融**：w/o Ada、w/o Traj、w/o CM、单信号奖励；
6. **扩展**：LETTER backbone，以及 Instruments / Yelp；
7. **可选增强**：LLM confidence sampling、LLM probability reward。

## 6. 验收门槛

达到以下条件，可认为公开实验主线复现成功：

1. 同一 backbone 上，GFlowGR-TB 相对 SFT 在四个指标上全面提升；
2. TB 不低于 DB，尤其在 Yelp / TIGER 这类中间状态歧义更大的设定；
3. $N$ 与 $\lambda$ 出现论文所述反向 V，最优点落在中等区间；
4. 去掉增强轨迹、改随机采样、或删任一奖励信号后，性能下降；
5. 推理链路与 SFT checkpoint 完全一致，只有微调目标不同。

## 7. 常见失败模式

| 现象              | 可能原因                         | 处理                                     |
| ----------------- | -------------------------------- | ---------------------------------------- |
| 相对 SFT 无增益   | $\lambda$ 太大或奖励尺度未归一   | 先固定 $\lambda=1$，标准化 $r_{\hat{y}}$ |
| 训练后期崩溃/变差 | 负样本过易或过难                 | 打开 CM curriculum，限制候选池           |
| TB 反而不如 SFT   | $Z$ 未正确学习，或只优化增强样本 | 保留正样本 SFT，检查 $R>0$               |
| 指标波动大        | seed / 早停 / beam 宽度不一致    | 固定三 seed，统一生成配置                |
| 看起来提升来自 CM | w/o CM 变体仍应接近主结果        | 按论文做无 CM 消融确认鲁棒性             |

## 8. 不可复现项

以下内容只能引用论文，不能在公开环境原样复刻：

- 淘宝搜索广告全量训练数据与特征；
- 生产协作模型、预算与拍卖耦合逻辑；
- 线上 A/B 的流量分层与商业指标口径。

公开复现的终点是：**在三个公开数据集、两个 backbone 上复现表 2 的相对结论与关键消融趋势**。
